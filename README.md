# 吸能奇点 · 共振进化

纯前端、手机优先的增量游戏。**零依赖、零构建**，打开即玩，支持离线收益与 PWA 安装。

它不是一个"点一下加一"的换皮放置游戏 —— 核心是**节奏操作 + 触屏吞噬 + 爆发技能 + Roguelite 构筑 + 形态分支 + 操作录制**六层叠加。

## 🎮 核心玩法

### 1. 共振节拍（操作层）
中央黑洞持续脉动并收缩。**在收缩到最小的一瞬间点击 = PERFECT**，点击力 **×10**，并叠 1 层**共振**。
- 共振每层 **+8% 全局产量**，最多 20 层 → 最高 **+160%**
- 3.2 秒不打出完美就开始掉层 —— 逼你一直保持手感
- 打出完美会扩散冲击波、屏幕闪光、震动，音高随共振层数升高
- 普通点击音高随**连击**沿五声音阶上升 → 连点会自然形成旋律

### 2. 拖动吞噬（触屏层）
屏幕上漂浮着能量光团。**手指按住并划过它们即可吸收**，收益 = 每秒产量的 35%（吃「吞噬者」词条 ×6）。
轻点 = 共振判定，拖动 = 吞噬，两套操作互不干扰。

### 3. 奇点爆发（爆发层）
点击与完美一击为**爆发槽**充能。充满后手动释放：
- 产量 **×100**，持续 **15 秒**（可强化到 ×250 / 更长）
- 期间**每次点击必定 PERFECT**
- 全屏进入狂暴视觉：红色脉动星云、爆发射线、粒子风暴、强震

### 4. 奇点词条（构筑层）
每次坍缩后 **3 选 1** 抽取词条，本轮生效，形成完全不同的 build：
- **贪婪** 产量 +65% / 点击 -40% · **暴怒** 暴击率 +20%、倍率 ×2.5
- **连锁** 完美后 3 秒产量 ×8 · **回响** 40% 概率额外 +1 层共振
- **新星** 爆发改为 ×250 · **虚空** 离线效率 +50%、上限翻倍
- 稀有度分色（普通 / 稀有 / 史诗），可花星尘**重抽**，也能**跳过换 1 星尘**
- 星尘强化「词条槽位」可把每轮词条数从 2 提到 5

### 5. 核心形态（不可逆分支）
坍缩 1 次后解锁，**每种形态直接改变核心循环**，飞升奇点后可重选：

| 形态 | 改变什么 |
| --- | --- |
| 🌀 **螺旋** | 共振层**永不衰减**，产量 +15% —— 最稳的挂机形态 |
| 🔺 **棱镜** | 每次点击**分裂成 3 段独立判定**，各自可能完美并叠共振；单段 ×0.45，共振上限 30 |
| 🦷 **噬渊** | 吞噬收益 **×12** 且每次吞噬叠 1 层共振；自动产量 ×0.35 |
| 📡 **脉冲星** | 爆发时长 **×2**、爆发产量再 **×3**；常态产量 ×0.6，脉动快 25% |

每种形态在 Canvas 上长得完全不一样：螺旋臂 / 旋转棱镜 / 环形尖齿 / 双锥辐射束。

### 6. 残响录制（把你的操作变成挂机引擎）
坍缩 2 次后解锁。点「录制残响」，在 **4 秒**内随便点，游戏会记录每次点击的**时间与是否完美**，
然后生成一个**自动演奏的分身**循环重放它：

- 收益 = 你的点击力 × 60%，**完美段位照样 ×10 并叠共振**
- 录制时的完美率直接决定这个分身的强度 —— 这是"练操作 → 换挂机收益"的通路
- 面板显示：录制点击次数 / 完美率 / 循环长度 / 已触发次数，可随时重录或清除

| 💫 坍缩转生 | 本次累计 1e12 能量 → ✦ 星尘，买 11 种永久强化 |

| 🌙 离线收益 | 最长 8 小时（虚空词条翻倍），基础效率 50% |

## 🎨 视觉与音效

- **Canvas 实时渲染**：事件视界黑球 + 三层旋转吸积盘 + 每个机器一圈轨道（粒子数随等级增长）+ 持续落入核心的粒子流
- 完美窗口时核心外圈亮起金色光环，脉动收缩本身就是判定提示
- 冲击波、火花池、屏幕震动分级、闪光、爆发射线
- **WebAudio 程序化合成音效**，零音频文件：点击音高随连击上升、完美和弦、暴击低频、吞噬扫频、爆发上升音

## 📱 手机体验

- 竖屏优先、`100dvh` + 安全区适配（刘海屏不遮挡）
- 整个舞台都是点击热区，拖动阈值 14px 区分轻点与吞噬
- 震动反馈分级（可在设置关闭）
- 设置页可**导出 / 导入存档码**，换设备或清缓存不丢档
- 加到主屏幕后全屏运行，断网也能打开（Service Worker）

## 🚀 部署

推 `main` 即自动部署（`.github/workflows/deploy.yml` 先跑测试再发布）：

```bash
git add -A && git commit -m "update" && git push
```

首次部署用一键脚本：

```powershell
.\deploy.ps1 -User <你的GitHub用户名>
```

线上地址：**https://btsunamib.github.io/xineqidian/**

> 工作流只发布 `index.html / css / js / sw.js / manifest / icon`，`.git`、`test`、`node_modules` 不会上传。

## 📐 关键数值

- 完美一击 **×10**，判定窗口基础 15% 相位（词条 +70% / 强化 +6% 每级）
- 共振 **+8% / 层**，上限 20 层，3.2 秒无完美开始掉层
- 爆发 **×100 / 15s**，充能：点击 +2.2、完美 +5.5、吞噬 +0.9、被动随共振增长
- 吞噬收益 = 每秒产量 **× 0.35**（吞噬者 ×6）
- 坍缩收益 `⌊5·√(本轮/1e12)·结晶倍率⌋`，飞升收益 `⌊3·√(累计星尘/2e5)⌋`
- 全局倍率 = 星尘共鸣 × 成就 × 碎片 × 共振层 × 词条 × 蜂群 × 连锁 × 爆发（全乘算）

## 💾 存档

自动保存到 `localStorage`（键名 `xineqidian_save_v2`），每 15 秒 + 切后台 / 关页面时保存。
导入时做字段校验：非法词条、越界层数、NaN 数值都会被清洗。
